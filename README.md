## Scope

This index covers:

- **Scrapers & crawlers** — headless browser automation, HTTP scrapers, site mirrors
- **Extraction & parsing** — HTML → structured data, readability/article extractors, table extraction
- **AI-ready packaging** — converters that output Markdown, JSON, or chunked text suitable for embeddings, RAG ingestion, or direct LLM context
- **Agent integrations** — MCP servers, agent skills, and SDK wrappers exposing scraping/extraction as tools
- **Anti-bot & rendering** — JS rendering, CAPTCHA handling, proxy rotation utilities

Out of scope: general-purpose ETL, database scrapers, non-web data extraction.
